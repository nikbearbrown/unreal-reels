# Examples

One tiny starter input per aspect, so you can run the [getting-started](../docs/getting-started.md)
walkthroughs with something concrete. These are illustrative only — no private media, voices, or
Soul IDs. Real reference images, audio, and renders live under `reels/` (git-ignored).

- [`songbird-demo/lyrics.txt`](songbird-demo/lyrics.txt) — a short demo lyric (bring your own `song.wav`).
- [`bios-demo/source.txt`](bios-demo/source.txt) — a short figure write-up (Ada Lovelace).
- [`explainer-demo/source.txt`](explainer-demo/source.txt) — a short concept (photosynthesis).

Run them through `scripts/segment_story.py` to produce a `beat_sheet.json`, then follow the
pipeline. See the full schema in [`../AGENTS.md`](../AGENTS.md).
