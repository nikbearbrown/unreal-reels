# Why a Wave Packet's Wiggles Move at Half the Speed of the Packet — Narration Script (Gate 1)

*Source: Candidate 06, `quantum-mechanics-vol1/chapters/08-the-free-particle-and-wave-packets.md`. Arc: Hook → Accumulation → Reveal → Implication. One sentence = one beat. ~12 beats ≈ 90s.*

**Production: mostly Manim, hook + bookends as doodles.** This one is **continuous motion** — a moving Gaussian envelope with internal crests, a tagged crest visibly lagging (move: *trace*). Real-time Manim updaters, not stroke-on. The hook is a **person** watching the packet (personality → doodle). Bear only in intro/outro. Accent Warm Slate `#5A5653` for the wave/envelope; a single red `#C0392B` dot tags one crest.

**Physics note:** for a free particle the crests (phase velocity) move *slower* than the envelope (group velocity) — about half. So relative to the blob the crests slide **toward the rear**, exactly the "slide backward" of the hook.
