# Why One Extra Atom of Distance Cuts a Tunneling Current Tenfold — Narration Script (Gate 1)

*Source: Candidate 14, `quantum-mechanics-vol1/chapters/06-finite-wells-steps-and-barriers.md`. Arc: Hook → Accumulation → Reveal → Implication. One sentence = one beat. ~12 beats ≈ 64s.*

**Production: mostly Manim, hook + bookends as doodles.** A scanning-tunneling-microscope tip *traces* a bumpy atomic surface at fixed height (move: *trace*, ValueTracker on the tip's x). The tunnelling current dies exponentially with the gap, so the gauge needle swings ~10× between an atom top and a valley — verified: the decay rate is set so one bump (top → valley) is exactly a factor of ten. This is the payoff of the tunneling/leakage videos (05, 13): the exponential makes single atoms readable. The hooks are a **person** amazed a microscope can feel one atom, then watching the needle drop when the tip lifts (personality → doodle). Bear only in intro/outro.
