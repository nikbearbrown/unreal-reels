# Why a Dim Blue Lamp Beats a Blinding Red One — Narration Script (Gate 1)

*Source: Candidate 03, `quantum-mechanics-vol1/chapters/01-why-classical-physics-failed.md` (photoelectric effect). Arc: Hook → Accumulation → Reveal → Implication. One sentence = one beat. ~12 beats ≈ 90s.*

**Production: mostly Manim, hook + bookends as doodles.** The mechanism — packets striking metal, an electron freed or not — is vector objects in motion, so it's Manim (move: *collapse*). The hook is a **person** with lamps (personality → doodle). Bear only in intro/outro.

**Colour is the teaching here:** red packets vs blue packets carry the "energy = colour" point, so this video uses **red `#C0392B` + blue `#2A6FB0`** (a colorblind-safe pair). Metal/electrons in ink.
