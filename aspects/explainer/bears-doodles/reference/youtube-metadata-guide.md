# YouTube titles, descriptions & hashtags for explainer videos — evidence-based

A cited, verification-pass guide for Bear's Notes (educational/explainer content). Claims are flagged: **[OFFICIAL]** = first-party Google/YouTube; **[STRONG]** = published methodology, correlational; **[WEAK]** = practitioner consensus / single vendor; **[DEBUNKED]** = circulates widely, failed verification — stop citing.

---

## What to unlearn first (popular stats that are folklore)

These appear all over SEO blogs and **did not survive verification** — don't build decisions on them:

- ❌ **"157 characters before the description truncates."** Not a YouTube figure — it's a borrowed Google *meta-description* number. YouTube gives no fixed truncation count (it's device/pixel-driven). Use ~150 chars / first 2–3 lines as the planning figure.
- ❌ **"16+ hashtags = all ignored."** The live policy cap is **60**, not 15. (15 is an old best-practice recommendation, not the hard limit.) [YouTube Help](https://support.google.com/youtube/answer/6390658?hl=en)
- ❌ **"Chapters give +20% watch time / +15% satisfaction"** and **"CTAs = +380% conversion."** Untraceable to any primary source.
- ❌ **Title CTR stats: "power words +34%," "numbers +20–36% CTR."** Unsourced vendor folklore; the one rigorous figure (Backlinko power words) is ~7%, not 34%.
- ❌ **"Keyword-stuffed descriptions rank better."** Backlinko found **zero correlation** between keyword-optimized descriptions and rankings across 1.3M videos. [Backlinko](https://backlinko.com/youtube-ranking-factors)

The honest engine of discovery is **title + thumbnail + first lines of the description + watch-time**, in that order. Metadata helps YouTube *understand* the video; viewer behavior decides how far it travels. [vidIQ](https://vidiq.com/blog/post/youtube-seo/)

## TITLES

**Character limits that actually bind.** The hard input cap is **100 chars** [OFFICIAL, [Help](https://support.google.com/youtube/answer/57407)], but that's irrelevant to design. The binding constraint is truncation, which is pixel-width-driven and varies by surface: desktop search shows ~**60–70** chars, the suggested sidebar ~**50–60**, and **mobile/TV feeds cut to ~40–50** — the tightest common surface. [WEAK, multiple 2026 measurements] → **Put the keyword and the hook inside the first ~40 characters; keep the whole title ≤ ~60.**

**Keyword placement beats keyword presence.** Exact-match keyword in the title has *negligible* ranking correlation (0.0097), and 55–62% of top-ranking videos don't even contain the exact phrase — but **90%+ contain at least part of it.** [STRONG but dated 2017–18: [Backlinko](https://backlinko.com/youtube-ranking-factors), [Briggsby](https://briggsby.com/reverse-engineering-youtube-search)] The rule is **broad/partial match, front-loaded** — not exact-string stuffing. Ranking titles average ~47–48 chars.

**Structure: no controlled study proves question vs. statement vs. how-to vs. number-led.** [WEAK — flag honestly] All "format X beats Y" claims are practitioner consensus. What *is* defensible is placement (front-load) and length (~45–50). Number-led and bracketed formats ([Tutorial], "3 Reasons…") aid scannability for evergreen content. [WEAK]

**Curiosity that isn't clickbait** has real grounding: Loewenstein's information-gap theory — curiosity comes from a *specific, bounded* gap, not vague mystery. [STRONG, peer-reviewed 1994] So **name the subject, withhold the resolution** ("Why Glass Isn't Actually a Solid"), never "you won't believe this." "Why" framing and concrete specificity (numbers) tend to outperform in educational niches. [WEAK] This is exactly the Veritasium "Legitbait" model — provoke a misconception, then deliver rigorously.

**Title A/B testing is now native (rolled out to all creators Dec 9, 2025).** [OFFICIAL/trade] Crucially, **Test & Compare optimizes for watch-time share, not CTR** [OFFICIAL, [Help](https://support.google.com/youtube/answer/16391400)] — a deliberate anti-clickbait design, which means **honest, descriptive, content-matching titles tend to win for explainers.** Up to 3 variants, ~2 weeks, desktop Studio only. (Vendor case data: title-only change drove +30% CTR [WEAK, TubeBuddy]; a thumbnail-test winner took 59.7% watch-time share → ~3× views [WEAK, vidIQ].)

**What to avoid — the hard facts.** Malicious clickbait (title promises what the video doesn't deliver) is an **enumerated spam-policy violation**: removal + strike, and 3 strikes/90 days = termination. [OFFICIAL, [Spam Policy](https://support.google.com/youtube/answer/2801973)] YouTube stepped up "egregious clickbait" enforcement in Dec 2024 (initially removing without a strike). Borderline-but-not-violating misleading content gets **reduced recommendation distribution**. There is **no official ban on ALL CAPS or emojis** — those are CTR/perception advice (use ≤1–2 emojis, selective single-word caps like "Do THIS first"), not enforcement.

**Title formulas for explainers** (each ≤ ~50 chars, keyword front-loaded, bounded gap, literally true):

- **Why-misconception:** `Why [belief] Is Wrong` → "Why Glass Isn't Actually a Solid"
- **Specific-number:** `[N] [Topic] ([twist])` → "3 Reasons the Sky Is Blue (Not What You Think)"
- **Front-loaded how:** `[Keyword]: How It Actually Works` → "Compound Interest: How It Actually Works"
- **Bounded gap:** `The Real Reason [phenomenon]` → "The Real Reason Bridges Collapse in Wind"
- **Question that names the gap:** `What Happens If [scenario]?` → "What Happens If You Fall Into a Black Hole?"

## DESCRIPTIONS

**Algorithm vs human use.** The description is a **context/discovery + human-readability surface, not a heavy ranking lever.** Backlinko: zero correlation between keyword-optimized descriptions and rank; videos with *no* description rank on page one. [STRONG, 2017] But it *is* matched in search and helps categorize the video (esp. into Suggested) — discovery-matching ≠ ranking weight. [OFFICIAL, [Help](https://support.google.com/youtube/answer/12948449)]

**Length & structure.** Hard cap 5,000 chars [OFFICIAL] — don't fill it. Above-the-fold is roughly the **first ~150 chars / 2–3 lines** before "Show more" (vidIQ: ~90 chars in search, ~160 on the watch page). Lead with the **hook + benefit + primary keyword**, not links. Target **~200–300 words** total (Backlinko: 200+ words; vidIQ: under ~1,000 chars) — complete, not padded.

**Keywords.** Primary keyword in the **first sentence (first ~25 words)**, repeated **2–3 times naturally** across the description; each video needs a **unique** description. [OFFICIAL + Backlinko 2024] Stuffing is a policy violation.

**Chapters/timestamps — exact spec (verified verbatim).** First timestamp **00:00**; **≥3** timestamps, **ascending**; each chapter **≥10 seconds**; manual overrides auto. [OFFICIAL, [Help](https://support.google.com/youtube/answer/9884579)] The real payoff: manual chapters can surface **Key Moments in Google Search**, letting one video rank for multiple queries (each linking to its chapter). [Google Search Central, vidIQ] Manual chapters also give you keyword control over chapter titles vs. generic auto ones.

**Links.** Put the **one primary link/CTA above the fold**; everything else below. Prefer **internal links** (your playlists/next video) to keep the session on-platform and grow watch time; links aren't penalized on YouTube the way they are elsewhere. [OFFICIAL + Sprout] Mirror the key link in a **pinned comment**. One-click subscribe: append **`?sub_confirmation=1`** to your channel URL. No proven penalty for outbound/source links — good for educational credibility.

**CTA.** Use **one primary CTA** per video (avoid choice paralysis), make it a **natural extension of the content**, and phrase it benefit-first ("Get the free worksheet for this lesson: …" beats "Check out my site"). Description + pinned comment are *persistent* CTAs (unlike timed end screens). [vidIQ 2024] A clear subscribe CTA correlates with "subscriptions driven," a ranking-positive signal. [Backlinko, dated]

**Description template (explainer):**
```
[HOOK + PRIMARY KEYWORD + benefit — first ~150 chars, this is your snippet.]

▶ [ONE primary link/CTA above the fold]

——— below "Show more" ———

CHAPTERS
0:00 Introduction
0:xx [Section — keyword where natural]
x:xx [Section]            (≥3, each ≥10s, ascending, starts 0:00)

WHAT WE COVER
2–3 sentences, primary keyword 2nd/3rd time + related terms. (~200–300 words total)

WATCH NEXT
→ [Playlist / "start here"]   → [one related video]

SOURCES & FURTHER READING
- [citation]   - [citation]

#PrimaryKeyword #Topic #Explained
```

## HASHTAGS

**How they work (2024–25).** Hashtags create a clickable results page of same-tag videos and contribute to search, but are a **categorization/navigation signal, not a primary ranking lever** — vidIQ's testing found a tag doesn't make a video discoverable unless the keyword is in the *title*. [OFFICIAL + vidIQ]

**Official rules.** Up to **3** most-engaging hashtags **from the description** display **above the title**; they must be in the *description* (title hashtags don't render above the title). Hard cap **60** → exceed it and **all** hashtags are ignored (and over-tagging risks removal). Unrelated/misleading hashtags can get a video removed. [OFFICIAL, [Help](https://support.google.com/youtube/answer/6390658)]

**Optimal number: current consensus = 3–5.** No credible source recommends 15 (that's a ceiling, not a target). The "3" camp means the 3 that display; "3–5" adds 1–2 in-description tags for categorization. [Sprout, Brandwatch, Hollyland]

**Mix:** one **broad** subject tag (reach) + **niche** topic tags (intent/alignment) + a **format/curiosity** tag explainer audiences search. Small channels should skew **long-tail** — hashtag traffic is only ~1–5% of views, but it matters proportionally more when you're small. [Monetag — and note: no rigorous small-vs-large experiment exists; this is inference.]

**The one real downside:** above-title hashtags are clickable links that send viewers *away* to a hashtag feed, competing with your title for the click. Put your **brand/series tag first** so the most-visible slot leads back into your own ecosystem.

**Recipe (all in the description, 4–5 total):**
`#BearsNotes` (brand/series, controls the top slot) · `#Physics` (broad) · `#QuantumMechanics` (niche) · `#Explained` or `#HowItWorks` (format) · *(optional)* a 2nd niche tag. For Shorts, lead with `#Shorts` + 2–3 topic tags.

## EXPLAINER-SPECIFIC: search vs browse, and what the best channels do

**Explainers are search-anchored, recommendation-amplified.** YouTube splits traffic into Search (intent/evergreen), Browse (Home/subs), and Suggested (Up Next). Educational/how-to is the canonical **evergreen, search-led** format — but in absolute terms, recommendations still drive most watch time even for educational viewers. [OFFICIAL taxonomy + TubeBuddy 2026; the "70% from recommendations" stat is real but 2018 and never refreshed — flag it.] Third-party estimates put browse at ~20–35% for educational channels vs 40–60% for entertainment (directional only).

**Resolving the search-vs-curiosity title tension** (best-sourced part):
- **Title Flip (small/growing channels):** launch with a **curiosity** title to win the first 48–72h of Browse/Suggested clicks; once it plateaus, swap to a **keyword-front-loaded** title for long-term Search. [vidIQ 2025]
- **Hybrid (established brands):** keyword + curiosity in one line ("Compound Interest: How It Actually Works").
- **A/B test** as the tiebreaker (and remember native testing rewards watch-time, favoring honest titles).

**Patterns of high-performing explainer channels** (observed templates):
- **3Blue1Brown** — `But what is a [X]?` + `[Concept] | Chapter N, [Series]` (fuses curiosity with a searchable concept).
- **Vox** — `[Topic], explained` suffix / `Why [X]` opener; each video paired with a companion article.
- **Veritasium** — declarative curiosity gaps: `The Most [X] in [Y]`, `The Biggest Misconception in [field]`; explicit "Legitbait" (intrigue that delivers).
- **Kurzgesagt** — `[Hook] – [Concept name]` dash structure; signature **"Sources & further reading"** block.
- **MinutePhysics / TED-Ed** — plain **question** titles ("What is Dark Matter?") + `| Series Ch. N`.
- **Cross-channel signatures:** the science tier puts **citations in the description** (SciShow "SOURCES," Kurzgesagt, Vox), and **no hashtag-stuffing** — established channels barely rely on hashtags. Title-case, ~5–9 words.

For Bear's Notes specifically: you're MinutePhysics-adjacent, so the **question / `Why [X]`** title is on-pattern and search-friendly; add the citations block (you already have sources per chapter) — it's the credibility signature of the genre.

## Additional native levers (folded from a third source — verified-safe)

Credible additions beyond title/description/hashtags. (The source they came from also repeated the debunked "15-hashtag cap" and overclaimed that keyword placement is a *ranking* factor — both corrected above — so these are kept, its hard numbers are not.)

- **Hidden Studio "tags" ≠ hashtags.** Separate from hashtags: a hidden keyword field (~500-char budget) in YouTube Studio, never shown to viewers. Official guidance says tags **"play a minimal role"** in discovery, but they help edge-case search — **misspellings and synonyms** of your keyword. Use **5–8**, broad→specific, don't stuff. [OFFICIAL: tags play a minimal role]
- **Captions / transcript are indexed text.** Upload accurate captions or fix the auto-captions, and **say your target keywords aloud** in the video — spoken content is indexed alongside metadata. High value for Bear's Notes because precise terms ("ultraviolet catastrophe," "wave function," names) are exactly what auto-captions get wrong. [STRONG mechanism]
- **Education category + content-type label.** Set the category to Education and, where available, the content-type label (concept overview, how-to, problem walkthrough, etc.) — makes educational intent explicit to the platform. [WEAK — verify the current label set in Studio]
- **Add to a playlist on upload.** Playlists extend sessions and give YouTube a topic cluster; do it at publish, not later. [WEAK]
- **Feed Search analytics back.** In Analytics → Traffic source → YouTube search, read the real queries surfacing your videos and reuse that exact phrasing in future titles/first-lines. [WEAK, sound]
- **AI retrieval is an emerging stream.** Well-chaptered explainers get cited by Google AI Overviews and answer engines (Perplexity/ChatGPT/Gemini); structuring the description as "who it's for / what it explains / concepts covered" matches how those systems evaluate sources. [WEAK — forward-looking, not hard-verified]

## RULES OF THUMB — repeatable checklist

**Title**
- [ ] Primary keyword + hook in the **first ~40 characters**; whole title **≤ ~60**, aim ~45–50.
- [ ] **Broad/partial** keyword match, front-loaded — not exact-string stuffing.
- [ ] Open a **specific, bounded** curiosity gap (name subject, withhold resolution). No vague "you won't believe."
- [ ] Title is **literally true of the video** (wins watch-time A/B testing; avoids the spam policy).
- [ ] Title Case, **≤1–2 emojis**, no ALL CAPS / no `!!!`.
- [ ] After ~1 week, run **Test & Compare** (2–3 honest variants).

**Description**
- [ ] **First ~150 chars = hook + benefit + primary keyword** (this is your snippet).
- [ ] **One primary link/CTA above the fold**; sources/extra links below.
- [ ] **~200–300 words**, keyword **2–3×** naturally, **unique** per video.
- [ ] **Chapters:** start `0:00`, **≥3**, **≥10s** each, ascending, keyworded titles.
- [ ] **Sources & further reading** block (credibility for explainers).
- [ ] **One** content-relevant CTA + a **playlist** link; mirror key link in a **pinned comment**; subscribe link uses `?sub_confirmation=1`.

**Hashtags**
- [ ] **3–5 total, in the description**; brand/series tag **first**.
- [ ] Broad + niche + format mix; only directly-relevant tags.
- [ ] Never exceed 60 (auto-ignore); don't title-stuff hashtags.

**Strategy**
- [ ] Title as a **searchable question** for evergreen reach where it fits the topic.
- [ ] Consider the **Title Flip** (curiosity at launch → keyword after plateau).
- [ ] Optimize for **watch-time + retention**, not raw CTR — a 10% CTR that bounces loses to a 5% CTR that holds.

**Native levers (do at upload)**
- [ ] Set **Education category** (+ content-type label if available).
- [ ] **5–8 hidden Studio tags** — include misspellings + synonyms of the keyword.
- [ ] Upload **accurate captions**; say target keywords aloud in the script.
- [ ] **Add to a playlist** on publish.
- [ ] Later: read **Search-query analytics** and feed real phrasing back into titles.
